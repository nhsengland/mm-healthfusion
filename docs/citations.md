# Citations

**mm-healthfusion** builds on several open-source tools and published methods. If you use
**mm-healthfusion** in your research, please also cite the relevant underlying tools listed below.

## Datasets

The project uses the following PhysioNet datasets. Each dataset page provides citation details
and BibTeX entries for that version.

- [MIMIC-IV 3.1](https://physionet.org/content/mimiciv/3.1/) and
  [MIMIC-IV-ED 2.2](https://physionet.org/content/mimic-iv-ed/2.2/)
- [MIMIC-IV-ECG 1.0](https://physionet.org/content/mimic-iv-ecg/1.0/) and
  [MIMIC-IV-ECG-Ext-ICD 1.0.1](https://physionet.org/content/mimic-iv-ecg-ext-icd-labels/1.0.1/)
- [MIMIC-CXR-JPG 2.1.0](https://physionet.org/content/mimic-cxr-jpg/2.1.0/)
- [MIMIC-IV-Note 2.2](https://physionet.org/content/mimic-iv-note/2.2/) and
  [MIMIC-IV-Ext-BHC 1.2.0](https://physionet.org/content/labelled-notes-hospital-course/1.2.0/)
- [MDS-ED 1.0.0](https://physionet.org/content/multimodal-emergency-benchmark/1.0.0/), the benchmark
  that informed the deterioration pathway
